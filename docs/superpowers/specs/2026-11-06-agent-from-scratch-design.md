# Agent From Scratch 设计

## 背景与目标

当前工作目录为空。用户提供了 20 期系列代码的整合稿，要求按给定目录结构在当前仓库创建完整、可运行的 TypeScript Agent 项目。交付必须包含原稿省略的模块，而不是保留无法解析的导入或占位实现。

用户提供的目录、公开接口和功能清单是既定设计；最后的“按上述结构逐文件创建到当前仓库”作为实施确认。不执行 Git 初始化、提交、远程推送或 GitHub 仓库创建。

## 范围

- Node.js 22+、TypeScript、ESM、Vercel AI SDK、LangGraph、Fastify。
- CLI 交互、ReAct/规划/反思编排、工具调用、上下文压缩、记忆、Skills、沙箱、安全、流式事件、视觉工具、MCP、评测、可观测性、HTTP/SSE 服务。
- 提供 Docker、Compose、GitHub Actions、环境变量示例与 README。
- 对原稿未给出正文的模块补齐功能完整、边界清晰的实现。
- 不接入真实第三方凭据，不主动启动 Docker 容器或外部 ChromaDB；这些能力通过配置和运行环境启用。

## 架构

### 核心调用链

`CLI/HTTP → AgentRunner → LangGraph → agent/tools/planner/reflect 节点 → LLMClient 与 ToolRegistry`

`AgentState` 使用 LangGraph Annotation 定义消息追加和字段替换语义。Agent 节点负责模型推理，工具节点负责并发执行与安全审批，规划节点处理复杂任务，反思节点从工具错误中提炼经验。路由必须考虑规划与反思开关，不能转到未注册节点。

### 配置与组装

配置加载器读取环境变量并合并默认值，支持 OpenAI 与 Anthropic 提供商。组装器创建模型客户端、提示构建器、沙箱会话、工具、记忆、Skills、安全系统、事件发射器、图运行器和服务连接管理器，并暴露统一关闭方法释放沙箱、记忆和模型资源。

### 上下文与记忆

上下文管理器负责消息预算和压缩；上下文组装器组合系统提示、记忆和对话。工具结果压缩器保留命令、错误和关键输出，对话压缩器可通过 LLM 摘要，无 LLM 时使用确定性摘要。

情景记忆持久化到本地 JSONL；语义记忆通过嵌入服务和向量集合检索。提供文件型向量存储作为默认后端，配置 ChromaDB 时可用远程集合。记忆管理器统一初始化、记录、检索、学习和关闭。

### 工具、Skills 与协议

工具由 Zod 校验参数并转换为 JSON Schema，执行结果使用统一 JSON 结构。内置文件和目录工具包含路径与输出大小约束；命令工具只通过所选沙箱执行，避免安全开关开启时绕过沙箱。

Skills 支持按需加载到提示词及持久化程序性经验。MCP 客户端使用官方 SDK 管理连接、列出和调用工具；MCP 服务暴露工具注册表。视觉模块提供桌面截图、图像压缩/分析和鼠标键盘工具，缺少桌面环境时返回明确错误。

### 沙箱与安全

沙箱后端统一实现 `SandboxBackend`。NSJAIL、Docker、Seccomp 不可用时自动降级；Local 仅作为显式警告的最后手段。命令执行包含超时、退出码、stdout/stderr、耗时和资源清理。

输入守卫结合规则与可选模型检测；命令分析器识别只读、写入、高危和阻断模式；审批门支持超时和拒绝；输出守卫屏蔽常见凭据。工具节点在执行命令前完成分析和审批，拒绝结果写回工具消息。

### 服务与可观测性

Fastify 提供健康检查、任务执行和 SSE 流式接口。事件发射器使用异步事件和连接订阅，连接关闭后清理监听器。Tracer 支持可选 Langfuse，Metrics 记录计数、耗时和 Token，Alerts 根据阈值产生告警，Dashboard 输出聚合快照。

### 评测

测试用例包含输入、期望和标签；Runner 支持并发上限、超时与 Pass@k；代码评分器执行确定性断言，模型评分器输出结构化评分，人工评分器支持显式评分输入。CLI `evaluate` 命令运行默认套件并输出报告。

## 数据流

1. 加载配置并组装依赖，选择可用沙箱。
2. 接收用户输入，执行输入安全检查。
3. 检索相关记忆，构建分层系统提示。
4. 复杂任务先规划；Agent 调用模型并产生文本或工具调用。
5. 工具调用经安全审批后执行，结果写入状态并返回 Agent。
6. 无工具调用且模型结束时保存最终答案与情景记忆；需要反思时进入反思节点。
7. CLI 输出结果，HTTP 返回任务结果，SSE 推送步骤和工具事件。
8. 关闭时停止服务、取消审批等待、销毁会话并释放资源。

## 错误处理

- LLM 对网络、限流和 5xx 使用指数退避，对认证、参数和上下文长度错误不重试；超时使用可取消信号。
- 工具参数错误可重试，未知工具和拒绝操作不可重试；异常不导致进程崩溃。
- 外部可选能力不可用时给出明确原因，不静默伪造执行成功。
- 本地沙箱不是安全隔离，文档和运行日志必须明确说明。

## 测试与验收

- 单元测试覆盖 Token 预算、工具参数/执行、上下文压缩、记忆持久化、命令安全、审批、Skills、指标和评测。
- 图测试使用确定性的内存模型，覆盖直接回答、工具调用、规划与反思，不访问真实模型。
- 服务测试通过 Fastify 注入检查健康检查和任务接口，并验证无效输入。
- 运行 `npm test`、`npm run build`、`npm run lint`，再执行真实 CLI 帮助、无凭据健康服务及评测命令。
- 最终检查工作区，删除构建和测试产生的临时文件，仅保留用户要求的项目文件与必要锁文件。
